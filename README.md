# To-Be-Determined

TBD is a 3D web-based interactive scheduler/time organizer with a social/friend component

CMPE 131 term project

# Building & Running
Node.js (v22.16.0) and npm (or any other package manager) need to be installed

Run the following in your local project (the following is for a Windows machine)

<br>

**Server (run this first)**

`cd server`

`npm install` (if dependencies haven't been installed yet)

`npm run dev`

Server should start on port 8000

<br>

**Frontend (should be run on a separate terminal than the server!)**

`npm install` (if dependencies haven't been installed yet; this is separate from the server)

`npm run dev`

Website will run on localhost:5173
